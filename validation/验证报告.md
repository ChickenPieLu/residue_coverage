## 启动、网络与退出

- 使用 macOS 标准 LaunchServices 启动后，约 4.152 秒本地页面返回 HTTP 200。
- 正常界面运行选择 MPS，模型加载约 0.566 秒；一次界面预测约 0.310 秒。
- Gradio 只监听 `127.0.0.1:7860`，没有监听局域网地址，`share=False`。
- 端口 7860 被占用时，应用自动选择 `127.0.0.1:7861`。
- 重复启动会复用已运行实例，不会再次加载模型或启动第二个服务器。
- “退出应用”会先向页面返回提示，约 2 秒后结束本地服务器、主进程和
  `resource_tracker` 子进程；退出后端口不再监听。
- 关闭浏览器标签页本身不会停止应用，必须使用页面中的“退出应用”按钮。
- 使用无效外网代理以及 Hugging Face 离线环境变量运行冻结自检成功，推理不依赖外网。
  本项是开发机上的阻断外网模拟，没有在物理断网的另一台机器上复测。

  推理成功，mask 为 512 × 512，coverage 为 89.3070220947%。

## 应用包内容

- 主程序为 Mach-O 64-bit arm64，不包含 Intel 切片。
- 应用包内只有默认模型
  `Contents/Resources/models/smp_unet_resnet34_imagenet_abc_bce_dice_seed42.pth`。
- 没有包含项目的 `.venv`、`.git`、`residue_background/`、`training/`、
  `legacy/`、`logs/`、历史模型或训练 checkpoint。
- 没有收集 Matplotlib、scikit-learn、SciPy 或 OpenCV 运行包。
- ZIP 使用 `ditto -c -k --sequesterRsrc --keepParent` 创建。重新解压后，
  应用结构、arm64 架构、模型校验和与代码签名验证均通过。

## 签名与 Gatekeeper

构建完成后执行了：

```bash
codesign --verify --deep --strict --verbose=2 dist/ResidueCoverage.app
codesign -dv --verbose=4 dist/ResidueCoverage.app
spctl --assess --type execute --verbose=4 dist/ResidueCoverage.app
```

`codesign --verify` 结果为 `valid on disk` 和
`satisfies its Designated Requirement`。签名详情显示：

```text
Identifier=local.residuecoverage.internal
Format=app bundle with Mach-O thin (arm64)
flags=0x2(adhoc)
Signature=adhoc
TeamIdentifier=not set
```

`spctl` 返回退出码 3，结果为 `rejected`。这是没有 Developer ID 签名且没有
Apple notarization 的内部测试版预期限制，不代表应用已通过 Gatekeeper 或 Apple 公证。
没有移除 quarantine 属性。若目标 Mac 的公司策略禁止运行未公证应用，应联系公司 IT，
或在正式分发阶段使用公司的 Apple Developer 身份重新签名并完成公证。
