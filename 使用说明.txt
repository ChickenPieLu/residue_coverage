ResidueCoverage（内部测试版）使用说明
=====================================

系统要求
--------
仅支持 Apple Silicon（M 系列芯片）的 Mac。不支持 Intel Mac，也不支持 Windows。
无需安装 Python、CUDA 或其他依赖，不需要管理员权限。

解压和启动
----------
1. 使用 macOS 自带的“归档实用工具”解压 ResidueCoverage-macOS-arm64.zip。
2. 保持 ResidueCoverage.app 完整，不要移动或删除应用包内部的模型和其他文件。
3. 双击 ResidueCoverage.app。应用加载模型后会自动在默认浏览器打开本地页面。
4. 第一次加载约 93 MB 的模型可能需要等待一段时间。

本内部测试版使用 PyInstaller 默认的 ad-hoc 签名，没有使用 Developer ID 证书，也没有
提交 Apple notarization（公证）。在其他 Mac 上，Gatekeeper 可能显示无法验证开发者或
拒绝打开。如果公司的安全策略禁止运行未公证应用，请不要绕过公司策略，应联系公司 IT；
后续正式分发应使用公司的 Apple Developer 身份签名并完成公证。

预测
----
1. 上传常见格式的农田图片。
2. 预测阈值默认为 0.5；如无特别需要请保持默认值。
3. 点击“开始预测”。
4. 页面会显示二值预测 mask 和秸秆覆盖率百分比。

隐私和网络
----------
程序完全在本机运行，Gradio 只监听 127.0.0.1，不创建公共分享链接，也不会上传图片。
程序可在断网状态下使用。

退出
----
使用完成后，请点击页面底部的“退出应用”按钮。页面显示已收到退出请求后，本地服务器和
应用进程会在约 2 秒内结束。仅关闭浏览器标签页不会停止应用。

注意
----
不要移动、删除或修改 ResidueCoverage.app 内部的模型及其他文件，否则模型校验或应用
签名会失效，程序可能无法启动。若应用损坏，请重新从完整 ZIP 解压。
